# 医院门诊预约管理系统

基于 **Qt 6 (Widgets)** 的桌面应用程序，实现医院门诊信息管理与患者预约的完整业务流程，为"专业技能实训 I（编程训练）"课程作品。

## 功能一览

| 模块 | 功能 |
|------|------|
| 门诊管理 | 添加门诊、编辑门诊、删除门诊、查看所有门诊 |
| 预约管理 | 预约门诊（日历选择日期 + 上午/下午时段）、取消预约（释放号源） |
| 查询功能 | 按门诊下拉框查询、按电话查询 |
| 数据持久化 | JSON 格式保存/加载（自动迁移旧版 txt 数据），保存失败弹窗告警 |

## 业务规则

- **容量控制**：每个门诊有容量上限，已满的门诊不可预约，查询"剩余号源"列实时显示
- **门诊号唯一**：添加时自动查重，编辑时门诊号锁定不可改
- **防重复预约**：同一电话不可重复预约同一门诊
- **删除保护**：删除门诊时若存在预约记录会明确提示，确认后一并删除
- **容量下限**：编辑门诊时容量不允许小于当前已预约人数
- **取消预约**：释放对应号源，该门诊重新可预约
- **预约时间**：日期控件限定不可早于今天、最远一年，自动拼接上午/下午时段

## 环境要求

- Qt 6.x（MinGW 编译器套件）
- C++17

## 编译与运行

### Qt Creator（推荐）

1. 用 Qt Creator 打开 `1.pro`
2. 选择桌面构建套件（如 Desktop Qt 6.11.1 MinGW 64-bit）
3. 点击左下角运行按钮（Ctrl+R）

### 命令行

```bash
qmake 1.pro
mingw32-make
./1.exe
```

## 数据存储

数据保存在可执行文件所在目录的 `hospital_data.json`，结构如下：

```json
{
  "version": 1,
  "clinics": [
    {
      "clinicNo": "MZ001",
      "clinicName": "内科门诊",
      "doctorNo": "D001",
      "consultTime": "周一至周五 8:00-17:00",
      "capacity": 10,
      "address": "门诊楼 2 层",
      "phone": "13800000000",
      "appointments": [
        { "name": "张三", "phone": "13900000000", "gender": "男", "age": 30, "appointTime": "2026-09-05 上午" }
      ]
    }
  ]
}
```

首次启动时若检测到旧版 `hospital_data.txt`（`|` 分隔格式），会自动读取并转换为 JSON 格式保存。

## 项目结构

```
1/
├── 1.pro               # qmake 工程文件
├── main.cpp            # 程序入口
├── clinic.h/.cpp       # 门诊数据模型（含容量判断、预约添加）
├── appointment.h/.cpp  # 预约数据模型
├── mainwindow.h/.cpp/.ui   # 主窗口（门诊表格、查询区、数据持久化）
├── addclinicdialog.h/.cpp/.ui  # 添加/编辑门诊对话框（编辑模式预填、门诊号锁定）
└── bookdialog.h/.cpp/.ui       # 预约对话框（日历选择日期、手机号校验）
```
